# Wedding Invitation Project

## Project Purpose

A mobile-first interactive wedding invitation website for Kyo/Henry and Aura.

Kyo/Henry is Korean-Australian.
Aura is Filipina.

The wedding visual identity combines:
- Christian faith
- Korean heritage
- Filipino heritage
- elegant modern wedding design

## Technical Requirements

- Static website only.
- HTML5, CSS3 and vanilla JavaScript.
- Must run on GitHub Pages.
- No React.
- No Node.js.
- No npm dependencies.
- No backend.
- No build step.
- Avoid external JavaScript libraries unless explicitly requested.
- Mobile-first responsive design.
- Desktop support required.
- Keep files organised under css/, js/, and assets/.

## Design Direction

Style:
- elegant
- romantic
- warm cream/ivory background
- restrained gold accents
- subtle Korean and Filipino influences
- Christian elements should be elegant rather than dominant

Avoid:
- childish UI
- excessive animation
- bright saturated colours
- clutter
- autoplay audio

## Development Rules

- Preserve mobile performance.
- Prefer CSS transforms and opacity for animation.
- Respect prefers-reduced-motion.
- Do not add unnecessary frameworks.
- Keep JavaScript readable.
- Do not commit or push unless explicitly requested.
